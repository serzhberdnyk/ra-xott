# RA XOTT

Публичная копия кода и изображений сайта, актуальная до v41. Обновлено 6 октября 2026 года.

Сайт: https://ra-xott-showcase.imberdnyk.chatgpt.site

## Файлы

- dist/ — код сайта и изображения v41
- CHANGELOG.md — понятное описание изменений v34–v41

## Страницы

- / — услуги и проекты рекламного агентства
- /led-ekrany/ — продажа LED-экранов для бизнеса
- /svetovye-vyveski/ — световые вывески и объёмные буквы
- /lyubov/ — личный сайт Любови Безус

## Локальный просмотр

    python3 -m http.server 8080 --directory dist

Открыть http://localhost:8080.

## Текущая версия

В v41 добавлены офисы в Сочи, Краснодаре и Армавире, контакты и соцсети агентства. Контактные ссылки агентских страниц ведут в Telegram @raxott. На главной добавлен публичный метатег подтверждения сайта Google. Личная страница /lyubov/ и изображения сохранены без изменений.

Сохранение кода в GitHub и публикация сайта выполняются отдельно.
