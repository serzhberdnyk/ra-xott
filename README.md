# RA XOTT — исходники восстановленной v2

Приватная резервная копия сайта RA XOTT: https://github.com/serzhberdnyk/ra-xott.
Восстановлено из сохранённого `RA-XOTT-preview-v2.html` от 2 октября 2026 года.

## Файлы

- `dist/index.html` — HTML, CSS и JavaScript сайта.
- `dist/assets/` — все шесть встроенных графических ресурсов исходного HTML.
- `RECOVERY.json` — происхождение копии и сведения о Sites.
- `SHA256SUMS` — контрольные суммы.

Выделение изображений выполнено без изменений содержания: обратная подстановка
встроенных ресурсов точно восстановила исходный HTML.

## Локальный просмотр

`python3 -m http.server 8080 --directory dist`

Открыть `http://localhost:8080`. Установка зависимостей не нужна.
Можно также открыть `dist/index.html` напрямую. Шрифты Arial/Helvetica системные.
Внешняя ссылка на bezuslove сохранена. Форма брифа сохраняет файл и не отправляет заявку.

## Резервирование и история

Рабочая ветка — `main`. После законченных правок проверять мобильную и большую
ширину, создавать коммит и сохранять изменения в этом репозитории.
Не смешивать проект с bezuslove или Factoria.

Отдельно сохранён `RA-XOTT-v2-backup.zip`: исходный автономный HTML,
выделенные ресурсы, контрольные суммы и `ra-xott-v2.bundle` с начальной локальной
историей восстановления. Большие архивы не дублируются в рабочем дереве GitHub.
Восстановление этой истории из ZIP: `git clone ra-xott-v2.bundle ra-xott`.
Архив — неизменяемый снимок до настройки GitHub, а не текущий экспорт ветки.

## Границы восстановления

Это отдельная восстановленная v2. Совпадение с текущим Git-репозиторием Sites
не проверено: доступ к нему был заблокирован в среде восстановления.
Старая история коммитов Sites не перенесена. История GitHub начинается с этого
восстановления. Никакие новые изменения не опубликованы в Sites.

Публикация выполняется отдельно после восстановления доступа к каноническим
исходникам Sites; сохранять существующий проект и его идентификатор.
Фоновая синхронизация GitHub и Sites не настроена.
