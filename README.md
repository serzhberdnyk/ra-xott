# RA XOTT

Исходники опубликованной версии Sites v31, сохранённые 5 октября 2026 года.

Сайт: https://ra-xott-showcase.imberdnyk.chatgpt.site

Исходный коммит Sites: 364147b173644c21e5bd419d622f63c798cc8b8f

## Файлы

- dist/ — сайт, стили, JavaScript и изображения
- sources/ — происхождение иллюстраций и сведения о кейсах и услугах
- tests/ — проверочные скрипты, если присутствуют в исходной версии
- .openai/hosting.json — привязка к существующему проекту Sites
- history/ — проверенная карта сохранённых версий v1–v31 и исходных коммитов
- RECOVERY.json — происхождение текущего снимка
- SHA256SUMS — контрольные суммы всех 55 исходных файлов публичного рабочего снимка

## Локальный просмотр

    python3 -m http.server 8080 --directory dist

Открыть http://localhost:8080.

## История и обновления

Предыдущая история GitHub сохранена. Новые снимки v31 и v32 добавляются отдельными коммитами поверх v30. Карта версий содержит оригинальные SHA Sites; коммиты снимков GitHub имеют собственные SHA.

Оригинальная история Sites до v30 включительно находится в отдельном сопровождающем архиве RA-XOTT_история_Sites_v1-v30_2026-10-05.zip. Архив не обновлён до v31/v32; инструкция восстановления и контрольная сумма находятся в history/README.md.

Из публичных source JSON удалены внутренние идентификаторы сообщений и private Library. Факты, ссылки на публичные источники, код и изображения сохранены.

Сохранение в GitHub и публикация в Sites выполняются отдельно. Автоматическая синхронизация и автоматическое развёртывание этими переносами не настраивались.
