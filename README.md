# RA XOTT

Публичная копия кода и изображений сайта, актуальная до v40. Обновлено 6 октября 2026 года.

Сайт: https://ra-xott-showcase.imberdnyk.chatgpt.site

## Файлы

- dist/ — код сайта и изображения v40
- CHANGELOG.md — понятное описание изменений v34–v40

## Страницы

- / — услуги и проекты рекламного агентства
- /led-ekrany/ — продажа LED-экранов для бизнеса
- /svetovye-vyveski/ — световые вывески и объёмные буквы
- /lyubov/ — личный сайт Любови Безус

## Локальный просмотр

    python3 -m http.server 8080 --directory dist

Открыть http://localhost:8080.

## Текущая версия

В v40 добавлена страница световых вывесок, уточнены клиентские тексты и указан год основания агентства — 2011. Существующие изображения и контактные адреса сохранены.

Сохранение кода в GitHub и публикация сайта выполняются отдельно.
