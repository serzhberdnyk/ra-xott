# RA XOTT — резервная копия v2

Восстановлено 3 октября 2026 года из сохранённого `RA-XOTT-preview-v2.html`.
Это самостоятельная копия сайта с изображениями, стилями и JavaScript.
Исходный HTML сохранён без изменений. При выделении изображений проверено,
что обратная подстановка даёт исходный файл в точности.

## Файлы

- `snapshots/RA-XOTT-preview-v2.html` — исходный автономный файл; можно открыть без сервера.
- `dist/index.html` — тот же сайт с изображениями в отдельных файлах.
- `dist/assets/` — изображения из исходного HTML.
- `RECOVERY.json` — происхождение копии и известные сведения о Sites.
- `SHA256SUMS` — контрольные суммы файлов.

## Локальный просмотр

Из папки проекта: `python3 -m http.server 8080 --directory dist`.
Открыть `http://localhost:8080`. Установка зависимостей не нужна.

## Границы восстановления

Копия основана на отдельном HTML v2. Её совпадение с текущим Git-репозиторием
Sites не проверено: доступ к нему заблокирован в текущей среде.
История старых коммитов Sites сюда не перенесена. Эта локальная история Git
начинается с восстановленной копии. Сайт повторно не опубликован.
Шрифты Arial/Helvetica системные; изображения локальные. Внешняя ссылка
на bezuslove сохранена. Форма брифа сохраняет файл и не отправляет заявку.

## Порядок сохранения изменений

После каждой законченной правки проверять сайт на мобильной и большой ширине,
создавать Git-коммит и отправлять его в отдельный приватный GitHub-репозиторий
RA XOTT. Не смешивать этот проект с bezuslove или Factoria.
Приватный GitHub-репозиторий: https://github.com/serzhberdnyk/ra-xott.
Загрузка файлов и проверка удалённой копии выполняются отдельно.
Публикация в Sites выполняется отдельно после восстановления доступа к
каноническим исходникам. Не заменять Site новым проектом.

Для автономного переноса использовать ZIP и сохранённый отдельно `ra-xott-v2.bundle`.
Восстановление истории: `git clone ra-xott-v2.bundle ra-xott`.
Это ручной порядок сохранения, не настроенная фоновая синхронизация.
