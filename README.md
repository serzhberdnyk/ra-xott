# RA XOTT

Исходники опубликованной версии Sites v30, сохранённые 5 октября 2026 года.

Сайт: https://ra-xott-showcase.imberdnyk.chatgpt.site

Исходный коммит Sites: 68d19306e49e6bdc93fcbdc7e12a5e1d76b173cf

## Файлы

- dist/ — сайт, стили, JavaScript и изображения
- sources/ — происхождение иллюстраций и сведения о кейсе
- .openai/hosting.json — привязка к существующему проекту Sites
- history/ — проверенная карта сохранённых версий v1–v30 и сведения о 33 исходных коммитах
- RECOVERY.json — происхождение текущего снимка
- SHA256SUMS — контрольные суммы всех 51 файла исходного рабочего снимка

## Локальный просмотр

    python3 -m http.server 8080 --directory dist

Открыть http://localhost:8080.

## История и обновления

Существовавшие коммиты восстановления v2 сохранены в истории GitHub. Текущий снимок добавлен поверх них. Оригинальная история Sites находится в отдельном сопровождающем архиве RA-XOTT_история_Sites_v1-v30_2026-10-05.zip; инструкция восстановления и контрольная сумма bundle находятся в history/README.md.

Оригинальные SHA Sites приведены в карте версий. Снимки GitHub получают свои SHA.

Внутренний идентификатор сообщения в sources/summit-case.json удалён из публичного снимка; факты кейса и остальные исходные файлы сохранены.

Сохранение в GitHub и публикация в Sites выполняются отдельно. Автоматическая синхронизация и автоматическое развёртывание этим переносом не настраивались.
