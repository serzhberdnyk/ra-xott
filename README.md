# RA XOTT

Публичная копия кода и изображений сайта, актуальная до v43. Обновлено 6 октября 2026 года.

Сайт: https://ra-xott-showcase.imberdnyk.chatgpt.site

## Файлы

- dist/ — код сайта и изображения v43
- CHANGELOG.md — понятное описание изменений v34–v43

## Страницы

- / — услуги и проекты рекламного агентства
- /led-ekrany/ — продажа LED-экранов для бизнеса
- /svetovye-vyveski/ — световые вывески и объёмные буквы
- /lyubov/ — личный сайт Любови Безус

## Локальный просмотр

    python3 -m http.server 8080 --directory dist

Открыть http://localhost:8080.

## Текущая версия

В v42 обновлены первый экран и подвал, добавлены отзывы клиентов, фотография благодарности Global Blockchain Summit, фотографии офиса и облегчённые варианты изображений. В v43 общий блок проектов заменён компактным кейсом Global Blockchain Summit перед отзывами и благодарностью: цель — 1000 участников, результат — 2000. Примеры работ внутри услуг, все 19 прежних изображений карточек услуг и личная страница /lyubov/ сохранены.

Сохранение кода в GitHub и публикация сайта выполняются отдельно.
