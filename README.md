# RA XOTT

Исходники опубликованной версии Sites v33, сохранённые 6 октября 2026 года.

Сайт: https://ra-xott-showcase.imberdnyk.chatgpt.site

Исходный коммит Sites: 4ac6f42c7d02f1b5d11f478fed1bd97a4f3af2c2

## Файлы

- dist/ — сайт, стили, JavaScript и изображения
- sources/ — происхождение иллюстраций и сведения о кейсах и услугах
- tests/ — проверочные скрипты, если присутствуют в исходной версии
- .openai/hosting.json — привязка к существующему проекту Sites
- history/ — проверенная карта сохранённых версий v1–v33 и исходных коммитов
- RECOVERY.json — происхождение текущего снимка
- SHA256SUMS — контрольные суммы всех 60 исходных файлов публичного рабочего снимка

## Локальный просмотр

    python3 -m http.server 8080 --directory dist

Открыть http://localhost:8080.

## История и обновления

Предыдущая история GitHub сохранена. Снимки v31, v32 и v33 сохранены отдельными коммитами поверх v30. Карта версий содержит оригинальные SHA Sites; коммиты снимков GitHub имеют собственные SHA.

Оригинальная история Sites до v30 включительно находится в отдельном сопровождающем архиве RA-XOTT_история_Sites_v1-v30_2026-10-05.zip. Архив не обновлён до v31/v32; инструкция восстановления и контрольная сумма находятся в history/README.md.

Из публичных source JSON удалены внутренние идентификаторы сообщений и private Library. Факты, ссылки на публичные источники, код и изображения сохранены.

Сохранение в GitHub и публикация в Sites выполняются отдельно. Автоматическая синхронизация и автоматическое развёртывание этими переносами не настраивались.

## Проверка DOM для изменения v31 → v32

    node tests/media-detail-dom.mjs

Скрипт сравнивает текущую версию со снимком GitHub v31 69c1c1d5391d5cfac131dd1ebbcafa9c26055dcd. Для отдельного локального тестового репозитория baseline можно переопределить переменной MEDIA_BASELINE_REF. Код сайта при этом не менялся.

В v33 удалена верхняя кнопка «Обсудить проект» и относящиеся к ней CSS-правила. Остальной код и файлы сайта сохранены. DOM-скрипт выше фиксирует изменение v31 → v32; он не является полной проверкой v33.
