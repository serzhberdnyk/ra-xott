## Известные пробелы

- Не восстановлены все технические этапы Sites между v43 и v143 и ранние этапы до v34.
- Большинство CMS-публикаций после переноса не имеют найденного отдельного соответствия `release ID → полный source snapshot`.
- Текущий CMS-release не подменён историческим Sites v144 или подготовленным UDS-пакетом.
- Даты из переписки являются датами сообщений о результатах. Они не гарантируют точное время деплоя.
- Не создавались Git tags, новые commits с задними датами или искусственная история изменений. Сайт при восстановлении истории не менялся.
- Список описывает подтверждённые вехи, а не полную приёмку всех пользовательских сценариев текущей версии.
