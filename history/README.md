# История RA XOTT

Проверено 6 октября 2026 года. Рабочий снимок: Sites v33.

- SITES-VERSIONS.json сопоставляет все сохранённые версии Sites v1–v33 их исходным коммитам
- SITES-HISTORY.json содержит исходные деревья и родителей коммитов, состав рабочего снимка и контрольные суммы
- GitHub сохраняет предыдущую историю восстановления v2 и отдельные снимки v30, v31, v32 и v33 по мере их добавления

Оригинальные коммиты Sites до v30 включительно с исходными SHA сохранены в сопровождающем архиве RA-XOTT_история_Sites_v1-v30_2026-10-05.zip. В нём 33 коммита и все source commit сохранённых v1–v30. Архив не обновлён до v31/v32/v33. Новые версии сохраняются отдельными снимками GitHub с собственными SHA; их оригинальные source SHA приведены в карте версий.

## Восстановление оригинальной истории до v30

Распаковать сопровождающий архив, затем:

    git clone ra-xott-sites-through-live-v30.bundle ra-xott-history
    cd ra-xott-history
    git checkout 68d19306e49e6bdc93fcbdc7e12a5e1d76b173cf

Восстановление в отдельную папку, git fsck и проверка всех source commit v1–v30 прошли.

SHA-256 bundle:

    4f55585edb1f50b3cd93f0d1c80a61c7090dddacf7b8f4722ac15109819b103a

Размер bundle: 38 284 864 байта. Подробные сведения сохранены в SITES-HISTORY.json.

Публичный рабочий снимок сохраняет файлы исходного сайта. Из provenance удалены внутренние идентификаторы сообщений и private Library; добавлены файлы описания и проверки. Полный список исключений находится в SITES-HISTORY.json.

Автоматическая синхронизация с Sites и автоматическое развёртывание этими переносами не настраивались.

DOM-тест v32 использует соответствующий GitHub-снимок v31 69c1c1d5391d5cfac131dd1ebbcafa9c26055dcd вместо исходного SHA Sites. Это позволяет запускать тест из обычного clone GitHub.
