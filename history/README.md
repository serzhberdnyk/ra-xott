# История RA XOTT

Проверено 5 октября 2026 года.

- SITES-VERSIONS.json сопоставляет все 30 сохранённых версий Sites v1–v30 их исходным коммитам
- SITES-HISTORY.json содержит 33 доступных исходных коммита Sites, их деревья и родителей, состав рабочего снимка и контрольные суммы
- GitHub сохраняет свою существовавшую историю восстановления v2; новый рабочий снимок добавляется поверх неё

Оригинальные коммиты Sites с исходными SHA сохранены в отдельном сопровождающем архиве RA-XOTT_история_Sites_v1-v30_2026-10-05.zip. В GitHub сохранён проверенный снимок v30 и карта версий; коммит GitHub имеет собственный SHA.

## Восстановление оригинальной истории

Распаковать сопровождающий архив, затем:

    git clone ra-xott-sites-through-live-v30.bundle ra-xott-history
    cd ra-xott-history
    git checkout 68d19306e49e6bdc93fcbdc7e12a5e1d76b173cf

Bundle содержит 33 коммита, в том числе source commit каждой из 30 сохранённых версий. Восстановление в отдельную папку, git fsck и проверка всех source commit прошли.

SHA-256 bundle:

    4f55585edb1f50b3cd93f0d1c80a61c7090dddacf7b8f4722ac15109819b103a

Размер bundle: 38 284 864 байта. Подробные сведения сохранены в SITES-HISTORY.json.

Публичный рабочий снимок отличается от исходного v30 только удалённым внутренним идентификатором сообщения в sources/summit-case.json и добавленными файлами описания и проверки. Исходные сведения сохранены в сопровождающем архиве.

Автоматическая синхронизация с Sites и автоматическое развёртывание этим переносом не настраивались.
