# Изменения RA XOTT

## V40 · 6 октября 2026 года

- Добавлена страница /svetovye-vyveski/ о световых вывесках и объёмных буквах с примерами работ, вопросами для расчёта и контактами
- Новая страница связана с главной и включена в sitemap; для неё заданы собственные title, description и canonical
- Упрощены клиентские тексты услуг, проектов, LED-страницы и личного сайта; уточнения об исторических данных сохранены там, где они нужны
- Указан год основания агентства — 2011
- Сохранены существующие изображения и контактные адреса
- В GitHub обновлены только публичные файлы сайта, README и этот список изменений; прежняя история сохранена

## V39 · 6 октября 2026 года

- Добавлена отдельная русскоязычная страница /led-ekrany/ о продаже LED-экранов для бизнеса
- Описаны подбор оборудования, согласование монтажа, эксплуатация, пять вопросов для первого расчёта и пять FAQ
- География поставки, комплектация, монтаж и поддержка согласовываются для конкретного объекта; рекламное размещение в Сочи описано как отдельная услуга
- Используются две уже существовавшие фотографии готового экрана и монтажной конструкции
- В описание услуги на главной добавлена обычная ссылка на новую страницу; остальные описания и контактные адреса сохранены
- Для новой страницы добавлены собственные title, description, canonical и запись в sitemap

## V38 · 6 октября 2026 года

- Для главной и /lyubov/ добавлены абсолютные canonical URL на bezuslove.com

- Содержимое страниц, контактные ссылки и оформление сохранены; canonical и sitemap не гарантируют индексацию

- Тексты кнопок, контактные адреса и обработчики сохранены
